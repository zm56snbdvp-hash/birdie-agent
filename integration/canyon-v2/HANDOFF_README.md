1. `INTEGRATIONSPROTOKOLL.md` lesen.
2. `QUELLEN.md` als fixiertes Quellenregister verwenden.
3. Den Handoff-Branch nur als Dokumentationsablage behandeln; er enthält keine angewendete Produktintegration.
4. Sobald `BirdieWorld_Emerald_Canyon_v2_Entwicklungspaket.zip` und der originale Schlag-App-Workspace verfügbar sind, zuerst `README_CANYON_V2.md`, den tatsächlichen Shot-Handler/Akzeptanzzweig und die echte Schlagansicht lesen.
